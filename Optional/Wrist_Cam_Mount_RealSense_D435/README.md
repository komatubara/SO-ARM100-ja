# Intel® RealSense™ D435 / D435i 用手首カメラマウント

<img src="../../media/d435_mount.jpg" width="600" />

この 3D プリント製マウントで、Intel® RealSense™ D435 または D435i を **SO-100 の手首** に簡単に取り付けできます。改造や追加金具は不要です。  
Feetech サーボに付属する予備ネジを再利用できます。

👉 [STL ファイルをダウンロード](stl/Wrist_cam_mount_RealSense_D435.stl)

<img src="../../media/d435_mount_render.png" width="600" />

### 組み立て手順

- 小さいネジ **5 本** でマウントを SO-100 の手首に固定する。
- **M3×6mm ネジ 2 本** で Intel カメラをマウントに固定する。
