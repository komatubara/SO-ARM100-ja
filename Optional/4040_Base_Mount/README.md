この 3D プリント製アダプタで、**SO-100 のベース** を標準の **40×40 mm アルミ押出材**（スロット幅 8.2 mm）に固定できます。  
ロボットアーム用の、しっかりしたモジュール式プラットフォーム向きです。

- 📦 [STL をダウンロード](./stl/4040_base_mount.stl)
- 📐 [STEP をダウンロード](./step/4040_base_mount.step)

### 🛠 組み立て手順

- アダプタをアルミフレームへ固定するには、**M4×16 mm ボルト ×1** と **M4 T ナット（8 mm スロット）×1** を使います。
- **SO-100 ベース** をマウントへ固定するには、**M4×30 mm ボルト ×4** と **M4 蝶ナット ×4** を使います。
> 穴径は 5 mm なので、M5 の金具でも構いません。
