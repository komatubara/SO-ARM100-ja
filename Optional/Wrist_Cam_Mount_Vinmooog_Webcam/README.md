# SO100 用手首カメラ取り付けガイド

## 概要
このガイドでは、**安価な Webカメラ** と 3D プリントした取り付け部品を使い、SO100 に **手首カメラ** を取り付ける手順を説明します。

## 必要な部品
### ハードウェア:
- [Vinmooog Webcam](https://www.amazon.fr/Vinmooog-equipement-Microphone-Enregistrement-conf%C3%A9rences/dp/B0BG1YJWFN/)
- **3D プリント部品:**
  - [改造手首](Optional/Wrist_Cam_Mount_Vinmooog_Webcam/stl/Updated_Wrist_Camera_Insert.stl)（**1 個** 印刷）。SO-101 では不要
  - [マウント](Optional/Wrist_Cam_Mount_Vinmooog_Webcam/stl/Webcam_Mount_Wrist.stl)（**1 個** 印刷）
- **金具:**
  - M3 ナット ×3
  - M3×12mm ボルト ×1
  - M3×35mm ボルト ×2

## 組み立て手順
### 手順 1: グリッパーマウントを印刷して準備する
1. 新しい **カメラマウント付き SO100 グリッパー** を 3D プリントする。
2. 3D プリント部品の専用スロットに **M3 ナット** を入れる。
3. **モーター** をグリッパーマウントに入れ、**グリッパー機構** を取り付ける。

    <img src="../../media/cam_mount1.jpg" width="300" />

### 手順 2: カメラマウントを取り付ける
1. **3D プリントしたカメラマウント** を用意する。
2. **M3×12mm ボルト** でカメラマウントを **グリッパーマウント** に固定する。先に入れた **M3 ナット** に噛み合うようにする。

### 手順 3: カメラを取り付ける
1. **Vinmooog Webカメラ** をカメラマウントに入れる。
2. 背面から **M3×35mm ボルト 2 本** でカメラを固定し、スロットにナットを入れる。

    <img src="../../media/cam_mount2.jpg" width="300" />
