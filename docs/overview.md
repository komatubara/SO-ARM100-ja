## 何ができるか

典型的な使い方は次のとおりです。

1. **テレオペレーション（遠隔操作）**  
   リーダーアームを人が動かし、フォロワーアームが同じ関節角度で追従します。机の上のブロックをつかむ、カップを移動する、といった作業を人が実演します。
2. **データ収集**  
   カメラ映像と関節角度の時系列が、LeRobot のデータセット形式で残ります。
3. **模倣学習**  
   集めたデモからポリシー（多くの場合 ACT や diffusion policy 系）を学習し、フォロワーだけである程度同じ作業を再現します。

高価な産業用アームと違い、部品は市販のバスサーボと 3D プリント部品が中心です。その代わり、剛性や繰り返し精度は「学習でカバーする」前提です。

## リーダーとフォロワー

| | フォロワー | リーダー |
| --- | --- | --- |
| 役割 | 実際に物をつかむ作業側 | 人が持って動かす操作側 |
| モーター | STS3215 7.4V、ギア比 1/345 が 6 個 | 自重を支えつつ手応えを軽くするため、関節ごとにギア比が違う |
| 先端 | グリッパー（ジョー） | ハンドルとトリガー |
| 電源 | 5V（7.4V サーボ）または 12V 版を選んだ場合は 12V | 常に 7.4V 系 |

SO-101 のリーダーは、肩・肘・手首でギア比を分けています。全部同じ強力モーターだと、人が動かすときに重すぎるためです。詳細は [組み立て]({{ '/assembly/' | relative_url }}) の表を見てください。

## SO-100 と SO-101

SO-100 が初代、SO-101 がその改良版です。

- 配線が整理されている
- 組み立て時にギアを外さなくてよい
- リーダー用モーターが更新されている

**新しく作るなら SO-101** です。旧版の部品表はリポジトリの `SO100.md` と、このサイトでは扱いません（原本に残っています）。

## LeRobot との関係

ハードウェアは The Robot Studio、ソフトウェア側の標準スタックは Hugging Face の [LeRobot](https://huggingface.co/lerobot) です。モーター設定、校正、データ記録、学習、推論までが一続きになっています。

コミュニティは [Discord](https://discord.gg/ggrqhPTsMe) にあります。ハードウェアの Issue は原本リポジトリ、ソフトウェアの手順は Hugging Face ドキュメントが起点です。
