## サーボが筐体に入らない / ガタガタする

ゲージ（`STL/Gauges`）でプリンタの寸法を見てください。PLA+、インフィル 15%、横穴にサポートを入れない、が原本の前提です。きついときは無理に圧入せず、ホルダー内面を軽く削るか、フローを見直して刷り直します。

箱を開けた直後の配線・電源・ジャンパは [サーボの準備]({{ '/servos/' | relative_url }}) にあります。

## モーターが応答しない

1. 電源が入っているか。操作中にプラグが抜けやすい、と公式も書いています
2. USB が PC とボードの間にあるか
3. 3 ピンがモーターに届いているか
4. Waveshare ならジャンパが **USB の B チャネル**
5. Linux なら `/dev/ttyACM*` の権限
6. ID 設定中に、モーターが 2 個以上つながっていないか

Windows なら Feetech 公式ソフト、Ubuntu なら FT_SCServo_Debug_Qt で、電源とバスだけ切り分けできます。

## `lerobot-find-port` に何も出ない

別のシリアルデバイスと混ざることがあります。ボードを抜いた瞬間に消える名前が正解です。USB ハブより直結の方が安定しやすいです。

## 校正中に肘がぶつかる / ギアが跳ねる

標準法は 6 軸を同時に中点へ保つ必要があります。難しい場合は [WebUI の 3 点校正]({{ '/calibration/' | relative_url }}) を検討してください。トルク 30% 制限と 1 軸ずつの記録が目的です。

可動範囲の端まで動かすときは、プラスチックが鳴いたらすぐ戻します。エンドストップにモーターを押し付けたままにしないこと。

## リーダーが重い / フォロワーが力不足

リーダーに 1/345 を全部使うと操作が重くなります。SO-101 のギア比表どおりか確認してください。フォロワーを強くしたいときだけ 12V 版＋12V 電源です。リーダーは 7.4V のままです。

## カメラがぼける・学習が弱い

多くの 32×32 モジュールは手動フォーカスです。640×480 / 30fps に落とし、レンズを回して作業距離に合わせます。可能なら手首と真上の 2 台。視点が毎回違うと模倣学習はかなり不利です。
