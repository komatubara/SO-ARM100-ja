## カメラ

| 用途 | 種類 | 向いていること |
| --- | --- | --- |
| 真上 | Webカメラ版 / 32×32 モジュール版 | 作業空間全体。単腕でも双腕でもアーム間隔を固定できる |
| 手首 | 32×32 UVC 一体型 | 部品が少なく、SO-100/101 両対応。既存 Wrist Roll の置き換え |
| 手首 | プラグオン（SO-100） | 既存部品を外さず着脱できる |
| 手首 | 六角ナット埋め込み（SO-101） | SO-101 のナット座に合わせた MF 設計 |
| 手首 | RealSense D405 / D435 | デプス。D435 は改造なしで手首へ |
| 手首 | Vinmooog Webカメラ | 安価な民生カメラ |

32×32 モジュールは 720p / 30fps クラスが目安です。学習時の解像度は **640×480、30fps** が公式周辺の推奨で、ネイティブの高解像度のままだとデータだけ太くなりがちです。レンズは手動フォーカスが多く、最初はボケているので実映像を見ながら回します。

オーバーヘッド側は、クランプでアームを机に固定するのと同じ締め方でマウントも押さえられます。双腕のときは Arm Base を 2 個使います。

## ベースまわり

- **Raised Base** — リーダーを高くする延長
- **4040 マウント** — 40×40mm アルミ（スロット 8.2mm）へ。M4×16 + T ナットでフレーム側、M4×30 と蝶ナット 4 本でアーム側。穴は 5mm なので M5 でも可。印刷向きは強度のため指定あり、サポート必須

## グリッパー

- **コンプライアント（TPU 95A）** — 外形は純正に近く、中空リブで対象に沿う。果物など壊れやすい物向け。SO-101 は印刷してそのまま交換。TPU は機種によってはヘッド改修が要る
- **新版（指 TPU / ベース PLA）** — サポートなしで指を刷れる。M3 が 2 本追加。XLeRobot 側のハードウェアも参照

触覚は AnySkin 系が原本から WowRobo へリンクされています。
