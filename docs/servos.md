## これは普通のラジコン用サーボではない

安価な SG90 などのホビーサーボは、基板から **信号線が1本ずつ** 出て、パルス幅（PWM）で角度を指示します。返ってくる情報はありません。

SO-101 の **STS3215** は **シリアルバスサーボ**（スマートサーボ）です。

| | ホビーサーボ | STS3215 |
| --- | --- | --- |
| 通信 | PWM、モーター1個につき信号1本 | 半二重 UART。1本のバスで複数台 |
| 配線 | 全部が制御基板に戻る | モーター同士を数珠つなぎ（デイジーチェーン） |
| 識別 | 配線で決まる | 各モーターが持つ **ID** |
| できること | だいたい角度だけ | 角度・速度・トルク、位置や温度の読み取り |

PC からは「ID 3 をこの角度へ」と送ります。配線が何本目かでは区別しません。だから **組み立てる前に ID を振り分ける** 必要があります。

## 箱を開けたら何が入っているか

1 個あたり、だいたい次が入っています。キットだと袋がまとまっていることがあります。

- サーボ本体
- 3 ピンケーブル（短い。コネクタは Molex 5264 系）
- 丸いホーン（出力軸に被せる円盤。25T）
- 小さいネジ（ホーン固定の M3、筐体固定の M2）

サーボ本体の両側に、**同じ形の 3 ピンコネクタが 2 つ** あります。どちらが入口でも出口でも構いません。電源（VCC）・GND・データが、この 3 本にまとまっています。

ラベルやシールに **C001 / C044 / C046** やギア比（1/345、1/191、1/147）が書いてあることがあります。SO-101 では機種を混ぜるので、袋を開けたらすぐ付箋で区別してください。見た目はほぼ同じです。

## 電圧を間違えない

| 種類 | 用途 | 電源 |
| --- | --- | --- |
| 7.4V 版（標準） | フォロワー全部、リーダー全部 | BOM どおり **5V 電源**（7.4V 定格を 5V で動かす） |
| 12V 版（任意） | フォロワーを強くしたいときだけ | **12V 5A 以上**。リーダーには使わない |

7.4V モーターに 12V を入れると壊します。USB だけ繋いでもモーターは動きません。**必ず DC ジャックに電源を入れてから** 通信します。PC の USB はデータの通路で、モーターの電力源ではありません。

ストール（軸が止まっているのに力を出し続ける状態）では 1 個あたり 2A 近く流れることがあります。6 個同時だと電源容量が足りず、ボードが落ちたり通信が乱れたりします。指定の電源を使ってください。

## 制御ボード（Waveshare）

ボードにはだいたい次があります。

- PC へつなぐ USB-C
- モーター用の DC 電源ジャック
- サーボ用 3 ピンコネクタが 2 口（どちらを使っても同じバス）
- 黄色いジャンパ 2 つ

LeRobot から PC で話すときは、ジャンパを **B（USB）** 側にします。A はマイコンの UART 用です。ここが違うと、ケーブルは刺さっているのにモーターが返事をしません。

接続の順番の目安:

1. ジャンパが B か確認する
2. サーボはまだ繋がない（または 1 個だけ）
3. DC 電源をボードへ
4. USB を PC へ
5. 電源アダプタのスイッチを入れる

抜くときは、できれば電源を切ってからサーボケーブルを抜きます。活線のまま何度も抜き差ししても動くことが多いですが、コネクタを斜めに抜くとピンが曲がりやすいです。

## ケーブルの向き

3 ピンは向きがあります。ハウジングの突起とボード側の切り欠きを合わせて、無理に押し込まないでください。逆差しすると電源と信号が入れ替わり、モーターやボードを壊すことがあります。

線の色はメーカーやロットで違います。色ではなく **コネクタの形** で判断します。

## 工場出荷時の状態

新品はだいたい次です。

- **ID = 1**
- **ボーレート = 1,000,000 bps（1 Mbps）**
- サーボモード（指定角度で止まる）

6 個をそのまま数珠つなぎすると、全部が ID 1 です。PC が「ID 1 へ」と送ると 6 個がいっせいに返事し、個別に設定できなくなります。公式が **1 個ずつ繋げ** と言うのはこのためです。組み立ててから直すと分解が必要になります。

## 最初にやること（組み立ての前）

机の上で、サーボ単体とボードだけで済ませます。3D プリント部品にはまだ入れません。

1. モーターを種類ごとに分け、使う関節の名前を書く（例: フォロワー ID1 土台、リーダー ID4 手首曲げ）。
2. LeRobot を入れ、`pip install -e ".[feetech]"` まで終わらせる。
3. ボードに電源と USB だけ繋ぎ、`lerobot-find-port` でポート名を控える。
4. **フォロワー用から**、公式どおり先端（グリッパー = ID 6）から土台（ID 1）へ、1 個ずつ ID を書く。
5. 書き終わったモーターに「ID 6」などとテープを貼る。電源を切っても ID は EEPROM に残ります。
6. リーダーも同じ。ギア比の違うモーターを、表の関節に割り当てる。

コマンドと画面に出る英文は [組み立て本編のモーター設定]({{ '/assembly/' | relative_url }}#モーターの設定) にあります。スクリプトが `gripper` だけ繋げと言ったら、本当にその 1 個だけです。前のモーターのケーブルをボードから外します。モーター側のコネクタにケーブルを残したままで構いません。

ID を書き終わってから、モーター同士をケーブルでつなぎ、ID 1（土台の旋回）からボードへ戻します。

## ホーン（円盤）

出力軸のギザギザに、付属の丸いホーンを被せます。組み立て本編では:

- 多くの関節は **上下 2 枚**。上だけ M3×6mm で固定。下はネジなし
- 関節 5（手首回転）は **1 枚だけ**

先にホーンを付けてから筐体へ入れる手順になっています。軸に対して斜めに締めないこと。金属ギアなので、ホーンが浮いたままネジを強く締めると歯が傷みます。

手で軸を回すときは、**トルクがオフ**（力を出していない）のときだけにしてください。通電して保持しているときに無理に回すとギアを削ります。

## 扱いで壊しやすいこと

- 同じ ID のまま複数つなぐ
- 電源なしで USB だけ、または電圧の違う電源
- ジャンパが A のまま LeRobot を動かす
- 活線のままコネクタを逆差しする
- 保持中に関節を手でねじる
- 端まで動かしたまま押し続ける（ハードストップ）
- 12V 版と 7.4V 版を同じ電源で混在させる

少し熱くなるのは普通です。触れないほど熱い、異音がする、動かないのに電流を食っている、は電源を切ってください。

## 動くかだけ先に確かめたいとき

Windows なら [Feetech 公式ソフト](https://www.feetechrc.com/software.html)、Ubuntu なら [FT_SCServo_Debug_Qt](https://github.com/Kotakku/FT_SCServo_Debug_Qt) で、ID 1 の新品 1 個をボードに繋いでスキャンできます。ボーレートは 1000000。スライダーで軸が動けば、配線と電源は正しいです。SO-101 では必須ではなく、LeRobot の `lerobot-setup-motors` だけで足ります。

次は [組み立て本編]({{ '/assembly/' | relative_url }}) の「モーターの設定」から、実際のコマンドに進んでください。
